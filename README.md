# Fors Corp

Marc Fors's independent AI engineering practice: products built end to end
with LLM agents as the delivery team, and nothing merges until it passes CI.

### Products
| | |
|---|---|
| **[forsight](https://github.com/Fors-Corp/forsight)** | Observability platform: a Go agent with ML anomaly scoring and forecasts, plus the React component library it renders through |
| **[fors-design-system](https://github.com/Fors-Corp/fors-design-system)** | Brand tokens and 30 Radix-backed React components: dark/light theming, WCAG 2.1 AA |
| **[health-overview](https://github.com/Fors-Corp/health-overview)** | Body-composition tracker: InBody PDFs or photos plus Apple Health on one timeline |
| **[marcfors.com](https://github.com/Fors-Corp/marcfors.com)** | Portfolio: first-party web vitals, a supply-chain audit on every build, six locales |
| **[file-cleaner](https://github.com/Fors-Corp/file-cleaner)** | Privacy-preserving macOS disk cleanup with a quarantine safety net |

### How we build
Claude Code, Codex, Cursor and Grok work each repo against versioned standing rules,
with MCP servers wired in. Required status checks, CodeQL and dependency audits gate
every merge, and Changesets turns every merged change into a published version.
