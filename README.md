# .github

Organization-wide defaults for [Fors Corp](https://github.com/Fors-Corp) repositories.

| File | Applies to |
|---|---|
| `profile/README.md` | The organization profile shown at github.com/Fors-Corp |
| `SECURITY.md` | Any repository without its own security policy |
| `CONTRIBUTING.md` | Any repository without its own contributing guide |
| `CODE_OF_CONDUCT.md` | Any repository without its own code of conduct |
| `ISSUE_TEMPLATE/` | Any repository without its own issue templates |
| `PULL_REQUEST_TEMPLATE.md` | Any repository without its own PR template |

A file of the same name inside a repository always takes precedence over the default here.
